GPU classes

What matters
  • VRAM — each GPU worker needs 1.6–4.2 GB. More VRAM = more workers per card (48 GB fits 6).
  • fp16 speed — newer generations run the models faster.
  • The CPU — GPU modules still decode, resize and post-process on the CPU. In our tests the GPUs averaged under 25% busy, so a much faster GPU gives less than its specs suggest. 57% of the time is CPU-only modules regardless.

What you get

~37 traits per leaf + ~16 per specimen, plus shape data. Most leaf traits come in px and cm. Column definitions: reports/Data/data_dictionary.csv.

Leaf size & outline15

  • Area incl. holes · area excl. holes · hole area · hole count
  • Perimeter · convex hull area
  • Convexity · concavity · circularity · aspect ratio
  • Bounding box width, height
  • Rotated box length, width · enclosing circle radius

Leaf landmarks10

  • Midvein length · lamina extent · tip–base length
  • Leaf width · petiole trace length
  • Apex angle + type (acute / obtuse / reflex)
  • Base angle + type
  • Midvein curvature

Petiole & LMA3

  • Petiole width · petiole length
  • Leaf mass per area (proxy, g/m²; no ruler needed)

Symmetry & quality9

  • Asymmetry index · signed left/right imbalance
  • Mirrored-half overlap (Dice) · midvein sinuosity
  • Solidity · perimeter ratio · hole fraction
  • Largest-piece fraction · archetype score + flag

Specimen~16

  • Has leaves / flowers / fruits · fertile
  • Counts: whole leaf, partial leaf, leaflet, fruit, fruits, flower, flowers, bud, roots, wood
  • Plant cover of sheet · archetypal leaf count · median leaf area
  • Scale (px/cm) + ruler type

Shape dataper leaf

  • 31 landmarks (x, y, confidence)
  • ECT: 360 × 360 matrix + images
  • Outline coordinates (full + simplified)
  • Momocs outlines + oriented images → elliptic Fourier descriptors in Momocs (R)
  • Leaf masks & cutouts · specimen masks · crops of 16 sheet objects
