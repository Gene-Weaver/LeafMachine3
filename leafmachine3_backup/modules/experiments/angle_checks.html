This is exactly how landmark_measurements will compute apex_angle/base_angle (degrees) and apex_angle_type/base_angle_type. Every number below is produced live by the same function that ships in core/landmark_metrics.py — so if these look right, the code is right. Image coordinates (y increases downward), so the leaf tip sits at the top and the base at the bottom.

The rule (matches LeafMachine2 determine_reflex):
  1. lamina_centroid = mean of the lamina-trace points (midrib).
  2. Arm vectors that point into the vertex: v_left = center − left, v_right = center − right ("from left→center", "from right→center").
  3. interior angle = angle between the two arms (0–180°).
  4. If both arms point toward the centroid → reflex, reported as 360 − interior. (Notched/emarginate apex; cordate/heart base.)
  5. Otherwise both arms point away from the centroid → interior angle, typed acute (<90°) or obtuse (≥90°).
